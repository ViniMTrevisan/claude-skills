# Handoff: concise task name

## Goal
State the concrete outcome.

## Current state
Separate completed, in progress, and not started.

## Evidence
List verified commands, outputs, and relative files.
For integration: `Source ref:` and `Target ref:`.

## Decisions
Record choices and rejected alternatives.
For integration: `Integration order:`.

## Next action
Give one imperative, executable next step with a command or file.

## Risks
List real uncertainty and the first likely failure.

## Boundaries
State unauthorized actions and omitted secrets.
For integration: `Merge authorization:`.

## Files
List only relevant relative paths.
